# Demo Script

## 1. Introduction
"This is the Sales Lead Management Tool, built with React, TypeScript, and Redux Toolkit. The app is designed to help a sales team review leads, inspect their details, and track follow-up activity in one place."

## 2. Show the lead list
"On the left side, you can see the sales lead list. Each row shows the lead's name and email address. I can quickly scan the list and select the lead I want to work with."

## 3. Select a lead
"I click on a lead, and the selected row is highlighted. This shows the app is responding to the current user selection and updating the state correctly."

## 4. Show lead details
"On the right side, the selected lead's full profile appears. Here we can see the lead's name, email, and phone number in a structured detail panel."

## 5. Show activity history
"Below the details, the activity log shows the lead's follow-up history. This is useful for tracking previous interactions and keeping communication organized."

## 6. Add a new activity
"I enter a follow-up activity note in the input field and click Add Activity. The app validates the input, and the new activity is appended to the lead's timeline."

## 7. Explain the system
"This application uses Redux Toolkit to manage the selected lead state and activity updates centrally. React handles the UI, TypeScript gives the app safer data structures, and the state is persisted in local storage so the latest activity remains available after a refresh."

## 8. Closing statement
"In short, this tool demonstrates a clean CRM-style workflow for selecting leads, viewing details, and logging follow-up activity in a maintainable and scalable frontend design."
